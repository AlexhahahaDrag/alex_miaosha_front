# 企业权限底座阶段一 Midscene.js 测试用例设计

## 1. 测试目标

本轮测试设计覆盖企业权限底座管理端阶段一重构后的 6 个 PC 页面：

- 用户管理
- 机构管理
- 角色管理
- 菜单管理
- 用户角色配置
- 机构用户配置

测试目标不是验证静态样式稿，而是验证原型落地后的核心行为：页面可达、数据不重复、级联筛选正确、右侧 Drawer 契约完整、权限配置差异预览可靠、删除阻断与数据隔离提示生效。

## 2. 执行约束

- E2E 自动化必须使用 Midscene.js：`@midscene/web` + `PlaywrightAgent`。
- Playwright 仅用于浏览器启动、登录、截图、URL 等基础能力，不允许用纯 selector 断言冒充 Midscene 行为检查。
- 每条自动化用例必须产出：
  - caseId
  - persona
  - 页面 URL
  - Midscene 断言摘要
  - 至少 1 张截图
- 推荐执行入口：
  - 本地：`npm run test:midscene:local`
  - CI：`npm run test:midscene:ci`

## 3. 账号与基线数据

| Persona | 用途 | 必备权限 |
| --- | --- | --- |
| `super_super` | 全量配置与高危操作验证 | 全部菜单、按钮、配置权限 |
| `rbac_user_manager` | 用户、角色配置闭环 | 用户管理、角色管理、机构/角色分配 |
| `rbac_readonly` | 越权与按钮隐藏验证 | 仅查看，不含新增/编辑/删除/配置 |

建议固定测试数据：

- 机构：`测试集团`、`测试集团 / 技术中心`、`测试集团 / 运营中心`
- 角色：`TEST_ADMIN`、`TEST_READONLY`、`TEST_TEMP_BIND`
- 用户：`test_rbac_admin`、`test_rbac_readonly`、`test_rbac_unassigned`
- 菜单权限码：`user:add/edit/delete`、`role:auth`、`menu:add/edit/delete`、`org:add/edit/delete`

| Case ID | 标题 | 前置 | 步骤 | 断言 |

## 6. 权限与数据隔离专项

| Case ID | Persona | 标题 | 断言 |
| --- | --- | --- | --- |
| `RBAC-S1-SEC-001` | `rbac_readonly` | 未授权按钮不可见 | 新增、编辑、删除、配置权限、批量操作均不可见或不可执行 |
| `RBAC-S1-SEC-002` | `rbac_user_manager` | 机构数据隔离 | 只能看到授权机构范围内用户和机构节点 |

| `RBAC-S1-SEC-004` | `rbac_readonly` | 直接访问越权路由 | 输入越权 URL 后不显示受限页面或被重定向 |

## 7. Midscene 脚本映射建议

建议在 `tests/midscene/rbac/cases/` 下拆分：

- `stage1-smoke.json`：`RBAC-S1-SMOKE-001 ~ 008`
- `stage1-regression.json`：`RBAC-S1-USER/ORG/ROLE/MENU/UR/OU/SEC-*`

脚本执行建议：

```bash
npm run test:midscene:local
npm run test:midscene:ci
```

增量调试建议：

```bash
$env:MIDSCENE_CASE_FILTER='RBAC-S1-SMOKE-005'; npm run test:midscene:local
```

第一批必须自动化：

- `RBAC-S1-SMOKE-001`
- `RBAC-S1-SMOKE-002`

- `RBAC-S1-SMOKE-006`
- `RBAC-S1-SMOKE-007`

第二批自动化：

- 全部 `RBAC-S1-ORG-*`
- 全部 `RBAC-S1-ROLE-*`
- 全部 `RBAC-S1-UR-*`
- 全部 `RBAC-S1-OU-*`

## 9. 通过标准

- Smoke：全部通过，允许因缺失测试账号明确 `skipped`，但不能出现 `failed`。
- Regression：关键阻断项必须通过。
- 不允许出现：
  - 用户重复数据
  - 越权菜单或按钮可见
  - 删除存在绑定关系的数据
  - Drawer 缺少保存/取消、错误提示或 loading 状态
  - 权限差异预览与实际保存结果不一致
