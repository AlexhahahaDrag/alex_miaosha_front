# 企业权限底座管理端重构阶段一任务拆解

## 1. 拆解原则

本阶段只面向 PC 管理端 `alex_miaosha_front`，后端 `alex_miaosha` 仅在接口能力、数据去重、绑定关系、删除阻断、数据隔离无法由前端独立完成时修改。禁止混入 `alex_miaosha_mobile` 移动端规范。

任务优先级遵循：

1. 先打通数据模型与接口契约。
2. 再落地公共组件和页面框架。
3. 再做页面逐个改造。
4. 最后补齐 Midscene.js 自动化验收。

实现阶段需要保留现有 Vue 3 + Ant Design Vue 工程基座，但视觉表现按 Stitch 的 Linear / Vercel 风格收敛：浅色背景、细边框、紧凑表格、黑色主按钮、右侧 Drawer 契约。

## 3. 前端任务拆解

### T02 公共 UI 契约

目标：

- 建立新增、编辑、详情、配置类操作统一使用右侧 Drawer 的实现模式。
- 为角色权限、用户角色、机构用户三类复杂配置提供可复用交互结构。

建议落点：

- `src/components/` 或现有业务公共目录：统一 Drawer 容器。
- `src/views/user/` 下模块内公共组件：权限树、差异预览、用户选择列表。
- `src/style/` 或页面 scoped less：Linear / Vercel 风格 token 落地。

子任务：

| 编号 | 内容 | 验收点 |
| --- | --- | --- |
| T02-1 | 统一 Drawer 结构 | 标题、对象摘要、主体、loading、错误提示、保存/取消齐全 |
| T02-2 | 差异预览组件模式 | 支持新增、移除、保持不变三组 |
| T02-3 | 权限树交互模式 | 支持全选、半选、批量展开、批量收起 |
| T02-4 | 双列表选择模式 | 支持已分配/可分配、搜索、批量添加/移除 |
| T02-5 | 视觉样式基线 | 紧凑表格、低圆角、细边框、黑色主按钮 |

### T03 用户管理

目标：

- 左侧机构树 + 右侧用户表格。
- 初始化时用户列表、机构树、角色列表并行加载。
- 首次查询全量用户，不等待机构树、不携带 `orgId`。
- 支持关键字、角色、机构组合查询，确保用户不重复。

主要前端落点：

- `src/views/user/userManager/index.vue`
- 用户管理 API 封装与类型配置文件

子任务：

| 编号 | 内容 | 验收点 |
| --- | --- | --- |
| T03-1 | 页面布局改为左树右表 | 机构树与用户表格首屏同时可见 |
| T03-2 | 初始化并行加载 | 用户、机构、角色请求互不阻塞 |
| T03-3 | 组合查询参数整理 | keyword、orgId、roleId/roleIds 可组合提交 |
| T03-4 | 用户 Drawer 改造 | 新增/编辑/详情不再使用居中 Modal |
| T03-5 | 数据去重保护 | 同一用户 ID 在当前页不重复 |

### T04 机构管理

目标：

- 支持无限级机构树或 Tree Table。
- 支持新增、编辑、删除、启停用。
- 删除前前后端双重校验下级机构和绑定用户。
- 拖拽调整层级若短期无法落地，需要提供替代方案。

主要前端落点：

- `src/views/user/orgInfo/index.vue`

子任务：

| 编号 | 内容 | 验收点 |
| --- | --- | --- |
| T04-1 | Tree Table 布局 | 层级缩进、展开收起、状态展示清晰 |
| T04-2 | 机构 Drawer 改造 | 新增/编辑/详情全部右侧 Drawer |
| T04-3 | 删除阻断前置查询 | 有子机构或绑定用户时不能提交删除 |
| T04-4 | 搜索与懒加载策略 | 大数据量下搜索和展开不卡顿 |
| T04-5 | 层级调整方案 | 支持拖拽或提供上移/移动到父级替代交互 |

### T05 角色管理

目标：

- 列表字段包含角色编码、角色名称、状态、绑定用户数、权限数量、更新时间。
- 行操作包含编辑、删除、配置用户、配置权限。
- 配置权限使用右侧 Drawer，保存前展示权限差异预览。
- 删除角色前检查是否仍绑定用户。

主要前端落点：

- `src/views/user/roleInfo/index.vue`
- 角色权限配置相关组件
- 角色用户配置相关组件

子任务：

| 编号 | 内容 | 验收点 |
| --- | --- | --- |
| T05-1 | 列表字段补齐 | 统计字段与更新时间可见 |
| T05-2 | 配置权限 Drawer | 权限树、按钮权限列表、批量操作齐全 |
| T05-3 | 权限差异计算 | 新增/移除/保持不变准确 |
| T05-4 | 配置用户入口 | 能进入或打开角色分配用户视图 |
| T05-5 | 删除绑定检查 | 绑定用户数大于 0 时阻断删除 |

- 删除前检查子节点。
- 权限标识与前端按钮权限体系联动。

主要前端落点：

- `src/views/user/menuInfo/index.vue`

| T06-3 | 权限标识联动说明 | 按钮权限标识与前端受控体系一致 |

### T08 机构用户配置

目标：

- 面向机构调整用户。
- 左侧机构树，右侧用户列表。
- 支持添加用户到机构、移出机构、跨机构移动用户。
- 支持搜索未分配用户。

建议落点：

- 新增或重构 `src/views/user/orgUserConfig/`。
- 若阶段一控制范围较小，可先作为机构管理辅助页或 Drawer 入口。

## 4. 后端任务拆解

后端只在前端无法独立满足业务一致性时修改。

建议落点：

- `alex_miaosha` 用户、机构、角色、菜单相关 Controller / Service / Mapper。
- Query、DTO、VO 分层。
- MyBatis Plus `LambdaQueryWrapper` / `LambdaUpdateWrapper`。

| 编号 | 内容 | 验收点 |
| --- | --- | --- |
| B01 | 用户分页支持多维查询 | keyword、orgId、roleId、roleIds 生效 |
| B02 | 用户分页去重 | 角色 join 或机构 join 不导致重复用户 |
| B03 | 角色分页统计 | 返回绑定用户数、权限数量、更新时间 |
| B04 | 机构查询与阻断 | 支持 orgName、orgCode、parentId、status；删除前检查子级与用户 |
| B05 | 菜单查询与阻断 | 支持 name/title、permissionCode、parentId、status；删除前检查子节点 |
| B06 | 角色用户绑定接口 | 支持查询已分配/可分配、批量保存差异 |
| B07 | 角色权限绑定接口 | 支持权限树、按钮权限、批量保存差异 |
| B08 | 机构用户调整接口 | 支持添加、移出、跨机构移动 |
| B09 | org_id 数据隔离 | 所有用户/机构相关查询受当前账号数据范围约束 |
| B10 | Controller 返回 VO | 禁止直接返回 Entity |

## 6. 建议执行顺序

### 第一批：基础契约

1. T01 接口契约与数据模型确认
2. T02 公共 UI 契约
3. B01/B02/B03/B04/B05 后端查询与统计缺口
4. Q01/Q03 测试 case 文件与 runner 支持

### 第二批：核心页面

1. T03 用户管理
2. T05 角色管理
3. T06 菜单管理
4. Q04/Q05 对应 smoke 自动化

### 第三批：配置闭环

1. T04 机构管理
2. T07 用户角色配置
3. T08 机构用户配置
4. B06/B07/B08/B09 后端绑定与隔离补强

### 第四批：收口验证

1. Q02 regression case 补齐
2. `npm run type-check`
3. `npm run build`
4. `npm run test:midscene:local`
5. 原型对比与 Review

## 7. 阶段出口标准

任务拆解阶段完成后，进入 TDD 实现前必须满足：

- 6 个页面的实现任务和测试任务都有明确编号。
- 后端修改点只围绕接口能力、绑定关系、删除阻断、去重、数据隔离。
- 每个页面至少有 1 条 smoke 用例与之对应。
- 所有新增/编辑/详情/配置类交互统一走右侧 Drawer。
- `progress.md` 已记录本任务拆解文档和验证命令。
